Die Browserbasierte Web-App ​Inverter erzeugt ein "fotografisches Negativ" und speichert die invertierten Bilder im Download-Verzeichnis

# ​Funktionen im Überblick:
**​Stapelverarbeitung:** Mehrere Bilddateien können ausgewählt werden.

**​Transparenz:** Transparente Hintergründe oder Bildabschnitte bleiben transparent erhalten.

**​Export der zugeschnittenen Bilder**: Als Dateiname_inverted ins Download-Verzeichnis.
